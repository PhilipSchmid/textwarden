# Reporting a security issue

If you suspect a vulnerability or security incident affecting TextWarden, [open a private GitHub report](https://github.com/PhilipSchmid/textwarden/security/advisories/new) or email [security@textwarden.io](mailto:security@textwarden.io). Please keep the details out of public issues, discussions, and pull requests.

## What to include

- The TextWarden version and macOS version, plus the browser or host app if relevant.
- What you observed, who or what could be affected, and when it happened if the incident is ongoing.
- If you can reproduce the issue safely, the shortest steps using made-up text. You can also report a concern based on what you have already observed.

TextWarden logs and diagnostic exports can contain pieces of your writing. A short description is enough for a first report. Remove private text, credentials, and identifying details from any excerpts or screenshots you choose to share.

## Supported versions

Security fixes target the [latest stable release](https://github.com/PhilipSchmid/textwarden/releases/latest). Reports about older releases, prereleases, and builds from `main` are welcome. Include the affected version or commit even if you cannot check a newer build.

## After you report

A maintainer will reply privately to discuss the impact and any fix. If you have not heard back within a week, please follow up by email with the report link or original email subject.

For confirmed vulnerabilities, we coordinate disclosure with the reporter and use [GitHub Security Advisories](https://github.com/PhilipSchmid/textwarden/security/advisories) to tell users which versions are affected and how to protect themselves.
